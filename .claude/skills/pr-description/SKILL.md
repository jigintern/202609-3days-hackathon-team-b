# PR本文テンプレート（このリポジトリ共通）

このリポジトリでPRを作成するときは、本文に以下の4項目を必ず含めること。

## 必須項目

1. **原因**: なぜ問題が起きるのか（仕様・実装上の理由）
2. **修正方法**: どう直したか（採用したアプローチとその理由）
3. **該当箇所**: 修正したファイル・関数・行
4. **簡易な比較図**: 修正前/修正後の違いが一目でわかる簡易図式（ASCIIツリーやコード片の並記など）

## テンプレート

```markdown
## 概要
<1行で何を直したか>

## 原因
<なぜ問題が起きるか>

## 修正方法
<どう直したか、なぜその方法にしたか>

## 該当箇所
- `path/to/file.ts` の `funcName`（行番号）
- ...

## 修正前/修正後
```
修正前                 修正後
<簡易図式>             <簡易図式>
```
```

## 注意
- ハッカソンリポジトリのルールにより、**PRのマージは行わない**（責任者がマージする）。
- 変更はコンフリクトを避けるため最小限・影響範囲を最小限にとどめる。
