# ようこそハッカソンへ 🎉

短期間でアイデアを形にするためのハッカソン用リポジトリです。作りたいものを、動くところまで持っていきましょう。

## はじめかた

```bash
git clone <このリポジトリのURL>
cd 202609-3days-hackathon-team-b
```

## スケジュール

| 日程  | やること           |
| ----- | ------------------ |
| Day 1 | アイデア出し・設計 |
| Day 2 | 実装               |
| Day 3 | 仕上げ・発表       |
